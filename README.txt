HIDE ALLIES - Fabric 1.20.1 (Java 17)

COMO COMPILAR
1. Instale o JDK 17.
2. Na pasta do projeto rode:  gradle build   (ou ./gradlew build se tiver o wrapper)
   Dica: abra a pasta no IntelliJ IDEA e ele configura tudo sozinho.
3. O .jar fica em build/libs/hide-allies-1.0.0.jar
4. Coloque o .jar na pasta mods junto com o Fabric API.

USO
- Tecla H (mude em Controles > Hide Allies): liga/desliga.
- /aliado add <nome>    /aliado remove <nome>    /aliado list
- /aliado clear         /aliado toggle
- Config salva em config/hideallies.json
